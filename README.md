# 🐦 Bird Detector Ultra

A Deep Learning powered Bird Sound Classification System capable of identifying **182 bird species** using environmental audio recordings.

Built with:
- TensorFlow / Keras
- Streamlit
- Librosa
- CNN-based Audio Classification
- Real-Time Microphone Detection
- Spectrogram Intelligence

---

# 🚀 Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/bird-detector-ultra.git
cd bird-detector-ultra
```

---

## 2️⃣ Create Virtual Environment

```bash
python -m venv venv
```

Activate environment:

### Windows
```bash
venv\Scripts\activate
```

### Linux / Mac
```bash
source venv/bin/activate
```

---

## 3️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Application

```bash
streamlit run app.py
```
